## Something I Have Learned About Git

I learned git keeps track of older versions of a project, which allows you to keep better track. If you end up messing something up, you can just go back to an older version.

## Helpful Git Command

`git add .`

This command adds everything from a git project into a local repo, which then allows you to commit. Its useful because you don't have to do "git add *blank*"
